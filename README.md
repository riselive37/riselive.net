# RiseLive Project

このプロジェクトは RiseLive のウェブサイトのソースコードです。

## 構成

- `index.html`: トップページ
- `about/`: 会社概要・私たちについて
- `news/`: ニュース・お知らせ
- `pricing/`: 料金プラン
- `works/`: 制作実績
- `contact/`: お問い合わせ
- `css/`: スタイルシート
- `js/`: JavaScriptファイル
- `images/`: 画像リソース

## 開発

このプロジェクトは HTML, CSS, JavaScript で構築されています。
